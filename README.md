# WebCraft Solutions – Portail React

Migration du portail E1 vers React (React 18, React Router 6, Bootstrap).

## Lancer le projet

```bash
npm install
npm run dev
```

## Structure

```
src/
├── App.jsx        # Composant racine
├── App.css        # Styles globaux
├── pages/         # Pages (Home, InscriptionPage)
├── components/    # Composants réutilisables
├── hooks/         # Hooks personnalisés (useFetch…)
├── utils/         # Fonctions utilitaires (validation…)
└── config/        # Constantes (URL des API…)
```
